# 文档贡献指南

产品文档通过 Pull Request 维护。提交前请确认内容对应的产品和版本明确，操作步骤经过产品团队验证，并且截图、日志或配置示例不包含凭据和个人信息。

## 页面约定

- 每页只聚焦一个产品、版本或任务，标题使用读者能识别的产品术语。
- 涉及兼容性、参数、供电、安全或固件更新的内容，注明适用型号和版本。
- 操作步骤应包含前置条件、执行步骤、预期结果和失败时的检查方式。
- 使用相对路径链接仓库内页面；为图片提供说明文字，并将图片放在所属产品目录下。
- 新产品按照[新增产品分类指南](new-product.md)创建目录和导航项。

## 本地检查

```bash
python -m pip install -r requirements.txt
mkdocs build --strict
```

Pull Request 会自动运行相同的严格构建检查。合并到 `main` 后，工作流会发布站点。
