# 常见问题

## 如何确认说明适用于我的设备？

核对页面标注的产品型号、硬件版本、固件版本和软件版本。若页面尚未标明适用版本，请联系该产品维护团队确认后再操作。

## 提交问题时需要提供什么？

请提供产品型号与版本、主机和运行环境、复现步骤、预期结果与实际结果、完整错误信息或日志，以及已尝试的排查步骤。分享日志前请移除密码、令牌和其他敏感信息。

## 如何新增产品文档？

准备好经确认的产品资料后，在 `docs/zh/products/` 和 `docs/en/products/` 下创建路径对应的页面，在 `mkdocs.yml` 登记导航与英文标题，并更新中英文产品总览。共享资源放在 `docs/assets/`，提交前运行页面覆盖检查和严格构建。
