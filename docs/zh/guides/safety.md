# 安全与维护

本页仅列出跨产品通用的提醒，不能替代具体产品的安全手册。产品专用的风险、急停方式和维护周期应以对应产品文档为准。

## 操作前

- 检查设备、线缆、连接器和安装结构是否完好，工作区域是否有障碍物。
- 确认产品型号、额定供电和当前使用的软件/固件版本。
- 首次运动测试时降低速度或负载，并确保急停和断电方式可用。
- 未确认设备状态前，不要执行自动运动、固件更新或参数写入。

## 操作中

- 让人员和无关物体远离运动范围；不要在设备运动时触碰活动部件。
- 出现异常声响、发热、碰撞、失控或通信中断时，按产品专用流程停止设备。
- 不绕过安全限制，不向设备发送未经确认的控制参数。

## 维护与问题记录

维护前按产品说明停止设备并隔离能源。记录维护日期、产品与版本、操作内容和发现的问题；不确定故障原因时，保留日志并联系对应产品支持人员。
